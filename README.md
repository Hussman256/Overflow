# Bitcoin Research Academy

A free, interactive learning platform that teaches anyone to find, evaluate, and produce Bitcoin research — no technical background required.

## What's Inside

- **6 structured modules** taking students from Bitcoin basics to publishing original research
- **Interactive slides** — flip cards, quizzes, comparisons, and assignments
- **AI Tutor** — context-aware help on every lesson
- **Dark / Light mode** — persistent theme toggle with zero flash on load
- **Progress tracking** — localStorage-backed XP and lesson completion
- **Social sharing** — module completion prompts to share on X/Twitter and LinkedIn
- **Wallet auth** — mock wallet connect + email/username sign-in

## Tech Stack

- [Next.js 16](https://nextjs.org) (App Router)
- [Tailwind CSS v4](https://tailwindcss.com)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide React](https://lucide.dev)
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Design

UI and visual language inspired by the [Bitcoin Design Guide](https://bitcoin.design/guide/) — accessible, open, and Bitcoin-orange.
